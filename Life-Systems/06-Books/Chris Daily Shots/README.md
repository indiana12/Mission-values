# Chris Daily Shots — Chapter-at-a-Glance Ritual

**Daily Loop (10–15 min)**
1. Spin the category wheel (money making, psychology, thinking, friendships, love, tech, science, mafia, leadership, creativity, systems, philosophy). No repeats until all covered.
2. Pick a book in that category (rotate through existing libraries + new finds).
3. Read/skim one chapter or key section.
4. Log the entry using the template:
   - Category + Book + Chapter/Page.
   - Author’s core idea (2–3 sentences).
   - Quick mindmap snapshot (key nodes + relationships; plain text bullets).
   - Visualization layer — imagine the scene or metaphor the author uses; describe it.
   - Real-life application (generic scenario, no private details).
   - Implementation nudge (what to do today).
   - Source/notes for future reference.

**Weekly**
- Review last 7 entries, pull one experiment into Jarvis or Vision.

**Monthly**
- Tag insights that need deeper journaling in the relevant book log (e.g., Psychology of Money Journal).

Use `Chris Daily Shots/YYYY/` for yearly logs. Link today’s entry from daily journal if needed.
